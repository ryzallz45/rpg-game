Aetheria: Legacy of the Dawn — Aset pihak ketiga
===================================

Sebagian besar aset di folder ini berlisensi CC0 1.0 (domain publik) sehingga
bebas dipakai, diubah, dan disebarkan — termasuk untuk keperluan komersial,
tanpa wajib atribusi. Pustaka three.js memakai lisensi MIT, dan font di
`assets/fonts/` memakai SIL Open Font License 1.1 (berkas lisensi terpisah).
Atribusi ditulis di sini sebagai bentuk terima kasih.

1) KayKit — Character Pack: Adventures (1.0)
   Pembuat : Kay Lousberg (https://kaylousberg.com — KayKit)
   Lisensi : CC0 1.0 Universal
   Sumber  : https://kaykit.itch.io/kaykit-adventurers
             https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
   Berkas  : Barbarian.glb, Knight.glb, Mage.glb, Rogue.glb, Rogue_Hooded.glb
   Isi     : karakter berig (rigged) + 75 animasi (idle, jalan, lari, serangan,
             lompat, terluka, mati, dll). Tekstur tertanam di dalam .glb.

2) Quaternius — Pig / Babi Hutan (dipakai sebagai "Babi Hutan" di game)
   Pembuat : Quaternius (https://quaternius.com)
   Lisensi : CC0 1.0 Universal (Public Domain)
   Sumber  : https://poly.pizza/m/u35l6uP5vj
   Berkas  : Boar.glb
   Isi     : model berig + animasi (Idle, Walk, Run, Headbutt, Death, dll).

3) three.js r128 — pustaka grafis + contoh resmi
   Pembuat : mrdoob dan kontributor three.js
   Lisensi : MIT
   Berkas  : lib/three.min.js, lib/loaders/GLTFLoader.js,
             lib/utils/SkeletonUtils.js, lib/postprocessing/*, lib/shaders/*
   Sumber  : https://threejs.org

4) ambientCG — Detail map permukaan (Tahap A)
   Pembuat : ambientCG (Lennart Demes)
   Lisensi : CC0 1.0 Universal (Public Domain)
   Berkas  : assets/textures/ground/forest_ground_04_diff_1k.jpg
             assets/textures/ground/dry_river_pebbles_diff_1k.jpg
             assets/textures/ground/rocky_terrain_02_diff_1k.jpg
             assets/textures/ground/white_stucco_02_disp_1k.png
             assets/textures/ground/white_stucco_02_disp_1k_8bit.png
   Sumber  : https://ambientcg.com/view?id=ForestGround04
             https://ambientcg.com/view?id=DryRiverPebbles
             https://ambientcg.com/view?id=RockyTerrain02

   Isi     : Foto permukaan 1024x1024 untuk tanah hutan, jalan kerikil, batu
             gunung, dan bump plester. Versi 8-bit adalah turunan dari
             displacement map 16-bit agar aman dipakai sebagai bumpMap.
